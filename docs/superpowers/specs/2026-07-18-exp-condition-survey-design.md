# 실험 뷰어 조건별 설문

## 목적

각 과제 직후 난이도와 시스템 안내의 영향을 1~7점 리커트 척도로 기록하고, 각 조건의 세 문제를 완료한 뒤 참가자가 해당 조건의 외부 설문을 진행하도록 안내한다.

## 화면과 흐름

1. 기존 과제 완료 뒤의 평정 화면에 체감 난이도(1~5점)를 유지한다.
2. 같은 화면에 다음 다섯 문항을 각각 1~7점 리커트 버튼으로 표시한다. 모든 문항과 난이도에 응답해야 다음 단계 버튼이 활성화된다.
   - 시스템이 제시한 내용을 주의 깊게 읽었다.
   - 시스템이 제시한 안내는 내가 하려던 행동을 한 번 더 돌아보게 만들었다.
   - 시스템이 제시한 내용을 읽기 전에, 이미 어떻게 행동할지 결정한 경우가 많았다.
   - 시스템이 제시한 안내는 나의 다음 행동에 영향을 주었다.
   - 시스템이 제시한 안내는 내가 깊이 생각하기보다 바로 행동하도록 만들었다.
3. 세 번째 과제의 평정을 저장한 뒤, 현재 `set_position`을 기준으로 조건 완료 안내 화면을 표시한다.
4. 첫째부터 셋째 조건은 “제공 받은 구글폼에서 'n번째 조건' 설문을 진행해주세요”라고 안내한다. 넷째 조건은 해당 안내와 함께 “'조건 비교' 설문까지 완료해주세요”라고 안내한다.
5. 안내 확인 후 다음 조건의 기존 트라이얼 또는 다음 과제로 이어진다. 마지막 안내 확인 후에는 기존 세션 종료 화면으로 이어진다.

## 데이터 계약

각 과제 결과 객체에 다음 정수 필드를 추가한다. 기존 CSV/JSON 내보내기와 서버 증분 저장은 결과 객체 전체를 사용하므로 별도 전송 형식 변경은 필요 없다.

- `system_content_reading`
- `system_guidance_reflection`
- `predecided_action`
- `system_guidance_influence`
- `system_guidance_immediate_action`

모든 필드는 1~7의 정수이며, 기존 `rating`은 난이도 1~5점으로 유지한다.

## 검증

- HTML/JavaScript 문법 검사
- 정적 검사로 5개 문항, 저장 필드, 조건 완료 화면 및 넷째 조건의 비교 설문 안내를 확인
- 기존 과제 결과의 난이도 저장과 다음 과제 전환이 유지되는지 확인
